# Plot Planner

**Open it: [justasbac.github.io/plot-planner](https://justasbac.github.io/plot-planner/)**

## How it is built

A single `index.html` file (no build step), hosted on GitHub Pages. Plans are stored in Firebase Firestore: shared settings in one document, each page in its own document, plus a small "who is online" list.
